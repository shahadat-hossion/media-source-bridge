Setup guide

Set up your server

  1. Create a Movies or Shows library in Jellyfin with a folder Jellyfin can write to. In Docker, mount the folder read-write and select its container path in Jellyfin.
  2. Open Setup Media. Under Default Save Locations, choose your libraries and select Save default locations.
  3. Under Add Server, enter a name, media type, and full private FTP, HTTP, or HTTPS directory URL. Enter FTP credentials if required. Select Test connection, then Add server when the test passes.

If the test fails, verify the URL and credentials and check that Jellyfin can reach the server. To recheck saved sources, use Configured Servers → Test all servers.

For torrent search, open Torrent Providers → Browse Providers. Select Test on a provider, then Add when the test passes.

Add your first title

  1. Open Search, choose a media type, and search for a title. If you have a URL from a configured source, use Import Link.
  2. Select FTP on a media server result. Jellyfin scans the library and opens the title when it is ready.

If you need a source or destination library configured, contact your Jellyfin administrator.
